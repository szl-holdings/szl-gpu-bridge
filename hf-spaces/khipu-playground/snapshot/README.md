# Khipu — receipt playground (research demo)

**Research demo, not a product.** The Khipu model family is not qualified for release:
the recorded 2/6 abstention result remains a release blocker and `publication_eligible`
is false. This page does not run a Khipu model.

Type a claim and see how a hash-chained khipu receipt is built, entirely in your
browser with SHA-256 (WebCrypto). Nothing is sent to a server and nothing is signed.
The receipt proves only that these bytes were hashed in this order in this tab;
it says nothing about whether the claim is true.

Khipu-family model repos showed about 6,600 downloads in the Hub's 30-day
counter on 2026-11-12. Download counts are not users or usage. Khipu models remain
unpromoted; see each model card for its evaluation status.
