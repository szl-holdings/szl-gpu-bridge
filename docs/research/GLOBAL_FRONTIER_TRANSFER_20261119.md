## Mathematical invariants for an SZL proving ground

**Evidence authority is not an output of a model.** Define \`admit = PASS\` iff *every* mandatory gate has independently verified \`PASS\`: source-revision identity, valid rights/license, real training owner, source/runtime digest parity, declared budget, checkpoint byte continuity, held-out quality, safety, runtime isolation, authenticated evidence/custody and authorized release. If a gate is \`HOLD\`, the product is HOLD; if an observation is missing it remains \`UNAVAILABLE\`. Neither a green CI check nor a digest string upgrades an unauthenticated signer.

**Separate non-atomic Salad measurements.** Let \`D\` be configured desired replicas from group GET, \`R_g\` be group-reported running instances, \`R_i\` be running instances from a *later separate* allowlisted instance GET and \`Q_i\` be provider ready flags. Compute and retain the tuple \`(D,R_g,R_i,Q_i)\`, with unknown values as \`None\`. A difference \`R_g != R_i\` is a **non-atomic sample discrepancy**, not a proof of crashed jobs, billing, completed training or a provider security incident. A \`running\` group with \`R_i=0\` remains HOLD until a fresh per-lane signed heartbeat and immutable checkpoint readback exist. The new \`reconcile_selected_instances\` code records only this bounded classification, not an effect.

**Performance metrics must share one benchmark timeline and hardware scope.** Candidate quantities are accepted answer tokens per measured GPU-second, step-time distribution, held-out correctly answered / offered items, and metered joules per accepted item. Never divide by an empty denominator or turn a GPU-device meter into process energy by inference. Compare controlled A/B runs with fixed model/dataset/harness revision, GPU class, test set, rights, warmup and seeds; reject contamination and silent model fallback.

**Formal math is a separate proof gate.** SZL's A1–A5 axioms, Lean/Lake, Khipu unit arithmetic, ancient Egyptian unit-fraction/Horus-Eye/Rhind-Akhmim carriers and Greek logic/arithmetical analogies may define candidate invariants. Only fresh Lean kernel execution over exact source plus checked assumptions can establish a theorem in scope. Manuscript-inspired code is not a digitized codex, historical mathematics is not a license grant, and no open \`sorry\` or Lambda unconditional-uniqueness counterexample is papered over. Ouroboros loops are bounded and terminate with typed receipts.

## Implementation and holds

1. **Implemented in this proposal:** selected group/instance readbacks reconcile only structured numerical signals with source-owned reason codes. Zero additional provider GETs, no redirects, no secrets, no write endpoint, no training/serving admission.
2. **Validation:** synthetic positive-replica/no-instance, parked group with lingering instance, non-atomic count conflict, missing denominator and privacy/GET-budget fixtures. Protected CI and CodeQL must pass before review and merge; this is still source only.
3. **Not implemented or promoted:** distributed RL engine replacement, new graph database, historical corpus ingestion, international model training, actual time-aligned trainer telemetry or trusted signer roots. Each requires separately approved, budgeted, rights-cleared canary and independent runtime readback.
4. **Pre-existing P0 holds:** [Salad capacity truth #251](https://github.com/szl-holdings/szl-gpu-bridge/issues/251), [single dispatcher owner #260](https://github.com/szl-holdings/szl-gpu-bridge/issues/260), [receipt trust #254](https://github.com/szl-holdings/szl-gpu-bridge/issues/254), [custody #387](https://github.com/szl-holdings/szl-org-health/issues/387), [private Memory Covenant schema #372](https://github.com/szl-holdings/szl-org-health/issues/372).

**Research-to-production rule:** source study -> explicit licensing/rights -> constrained proof-backed candidate -> fixture tests -> real hold-out A/B -> signed and independently verified deployment receipt -> staged authorized release. Anything less remains \`HOLD\` or \`UNAVAILABLE\`.
