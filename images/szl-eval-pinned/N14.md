# N-14 coverage (this image)

Requirement N-14 (ADR-0017 / PROPOSAL.md §9): a Nemotron-capable pinned eval image
with transformers ≥ 5.3, mamba-ssm, causal-conv1d, and a vLLM build that supports
NemotronH, plus CUDA 12.x / sm_90 for H100/H200.
